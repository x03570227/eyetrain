# 视力训练记录台

一个**纯本地、零后端**的视力训练记录工具：双击 `index.html` 就能用，不装环境、不启服务、不上传任何数据。

每天记录一次「训前 / 强化训练后 / 秒视」的左眼、右眼、双眼视力，自动画成折线图；内置一个全屏「测训」舞台，可以直接用屏幕上的视标给孩子做训练，测到达标的档位自动写回当天的记录。

---

## 为什么做这个

家里孩子在医院 / 机构做视力训练，要每天记录视力变化。纸质的记着容易丢、也看不出趋势；现成的 App 要么要注册、要么数据存在别人服务器上。

所以这个项目的原则是：

- **数据只在你自己的浏览器里**，没有账号、没有服务器、没有网络请求。
- **给不熟悉电脑的人用**：控件大、步骤少、能点就不打字——视力值用「大号输入框 + ▲▼ 微调 + 常用值快捷按钮」输入，全程可以只用鼠标。
- **双击就能跑**：不需要 Node、不需要 `npm install`、不需要本地服务器。

---

## 功能

### 1. 当天记录

- 顶部日期可切换（前一天 / 后一天 / 回到今天），选哪天就加载哪天的数据，没有就空表单。
- 一组表单记录四类数据：
  - **训前视力**：左眼 / 右眼 / 双眼
  - **强化训练视力**：左眼 / 右眼 / 双眼
  - **秒视视力**：左眼 / 右眼 / 双眼
  - **测量距离**：测视距离、训练距离（界面按**米**填，入库按**厘米**存）
- 视力值支持上下微调（步长 0.1）和常用值快捷按钮；距离步长 1 米，也支持直接输入小数。
- 备注栏可写训练时长、配合情况等。
- 已有记录时可以「修改 / 删除 / 取消」，保存时自动更新（含自动维护的修改时间）。

### 2. 历史记录

- 顶部日期范围筛选 + 快捷选择（近 7 天 / 近 30 天 / 近 90 天 / 全部，默认近 30 天），改完立刻刷新。
- 三张折线图：**训练前视力**、**强化后视力**、**秒视视力**，每张图三条线（左眼 / 右眼 / 双眼），横轴日期、纵轴视力值。
- 底部明细表格按日期倒序排列，可直接跳转编辑某一天。

### 3. 测训（全屏视标训练）

- 按 GB 11533-2011 标准画「E / 山字」视标，共 14 个档位（4.0 ~ 5.3，对应小数视力 0.1 ~ 2.0）。
- 三种模式：
  - **测视**：答对即记录并自动进下一档；
  - **训练**：答对才换图案，答错保留当前一组继续练，档位由操作者手动控制；
  - **秒视**：每组只显示 3 秒，超时自动换一组（不计对错）。
- 支持左眼 / 右眼 / 双眼，舞台上用彩色圆点提示当前训练眼和当前模式。
- 全屏方向键作答：**单击方向键 = 回答朝向，双击方向键 = 切档 / 切模式 / 切眼睛**。
- 只有本档答对次数达到「强化次数」（可设置，默认 4 次）才写入记录，避免把蒙对的档位记成真实水平。
- 底部常驻统计条：总次数 / 成功次数 / 成功率。
- 首次使用需要用尺子量一下屏幕上的校准条（标称 100 mm），填进实测毫米数，之后视标大小才准；换电脑或改了浏览器缩放要重新量。

### 4. 多用户

顶栏可以切换用户（比如家里两个孩子各记各的），已有的记录会归到「历史记录（未归属）」占位用户下，不会丢。

## 快速开始

1. 下载或 `git clone` 本仓库；
2. **双击 `index.html`**，用 Chrome / Edge 打开即可（见下方 [浏览器支持](#浏览器支持)）；
3. 第一次打开会有一个说明页，看完点「我知道了，开始记录」；
4. 首次进入「测训」页先做一次屏幕校准，然后就可以开始记录了。

> 不需要构建、不需要安装依赖，`vendor/` 里已经放好了运行时需要的库。

## 数据存在哪里 / 怎么备份（重要）

- 存储分两层，别弄混：
  - **上层是 SQLite**（[sql.js](https://github.com/sql-js/sql.js)，SQLite 编译成 WASM），整个库在**浏览器内存里**跑，页面里的查询、建表、唯一约束都是真 SQL；
  - **下层是 IndexedDB**，只负责持久化：每次改动把整个 SQLite 库导出成一份**二进制快照**存进去，打开页面时再整份读回来。
  - 换句话说，IndexedDB 里存的是「一个 SQLite 文件的字节」，不是按条存的业务记录。这样刷新、关浏览器都不丢。
  - 曾经试过直接选目录写回本地文件，但 `file://` 下用不了（见下方说明），所以自动保存只剩 IndexedDB 这一条路。
- **IndexedDB 里那份是唯一的副本**，所以：
  - 跨设备搬移数据只能靠顶栏的「导出备份 / 导入」。导出会下载一个 `eyerecord-YYYY-MM-DD` 文件，导入时选中它即可。
  - **清理浏览器数据（缓存 / Cookie）会连记录一起清掉**，清之前一定先导出一份。
  - 换浏览器、换电脑也要先导出再导入。
- **不要把 `index.html` 挪到别的文件夹。** 浏览器是按 html 文件所在目录分区存储 IndexedDB 的，挪走之后记录会像「消失」了一样（挪回来就又有了）。
- 如果浏览器没有 IndexedDB，会自动降级成「内存模式」：可用，但每次保存都会自动下载一份备份文件，关闭页面即丢失，需要手动导入。
- 导出的备份就是标准 SQLite 文件，也可以用 [DB Browser for SQLite](https://sqlitebrowser.org/) 或 `sqlite3` 直接打开查看。

> 为什么不用「选目录写回本地文件」：`file://` 协议下页面源是 `null`（不透明源），File System Access API / OPFS 会被浏览器硬性禁用，双击打开 html 时根本调不了。

## 目录结构

```
.
├── index.html              # 唯一入口页面
├── assets/
│   └── style.css           # 样式
├── js/
│   ├── db.js               # 数据层：sql.js 建表/查询 + 快照存入 IndexedDB、导出/导入
│   ├── chart-core.js       # 视标绘制与档位表（4.0~5.3 / 0.1~2.0）
│   ├── train.js            # 测训舞台：全屏视标、作答判定、写库规则
│   └── app.js              # 页面逻辑：当天记录、历史图表、用户切换
├── vendor/                 # 第三方库（已随仓库提供，无需 npm）
│   ├── sql-wasm.js         # sql.js
│   ├── sql-wasm-binary.js  # SQLite WASM（base64 内嵌，避免 file:// 下的跨域加载）
│   └── chart.umd.js        # Chart.js v4.5.1
└── ai/                     # 需求与设计文档（开发参考，运行时不需要）
```

## 技术栈

- 原生 HTML / CSS / JavaScript，**零构建、零框架**
- [sql.js](https://github.com/sql-js/sql.js) — SQLite 编译成 WASM，在浏览器里跑真正的 SQL
- [Chart.js](https://www.chartjs.org/) 4.5.1 — 折线图
- IndexedDB — 数据库快照的持久化

## 数据表

```sql
CREATE TABLE vision_train_record (
  id             INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id        TEXT NOT NULL,     -- 关联用户
  record_date    TEXT NOT NULL,     -- 记录日期 YYYY-MM-DD
  pre_left       REAL,              -- 训前左眼
  pre_right      REAL,              -- 训前右眼
  pre_both       REAL,              -- 训前双眼
  train_left     REAL,              -- 强化训练左眼
  train_right    REAL,              -- 强化训练右眼
  train_both     REAL,              -- 强化训练双眼
  second_left    REAL,              -- 秒视左眼
  second_right   REAL,              -- 秒视右眼
  second_both    REAL,              -- 秒视双眼
  test_distance  INTEGER,           -- 测视距离，单位 cm
  train_distance INTEGER,           -- 强化训练距离，单位 cm
  remark         TEXT,              -- 备注
  gmt_created    DATETIME DEFAULT CURRENT_TIMESTAMP,
  gmt_modified   DATETIME DEFAULT CURRENT_TIMESTAMP,
  UNIQUE(user_id, record_date)
);
```

另有 `user_config` 表保存每个用户的测训设置（强化次数、确认效果、记录时机、图表校准、一次展示几个图标等）。首次打开自动建库建表，无需任何初始化步骤。

## 常见问题

**Q：打开页面是空白 / 一直显示「未连接」？**
A：确认 `vendor/`、`js/`、`assets/` 三个目录和 `index.html` 在同一层，浏览器控制台如果有 `缺少 vendor/...` 的报错，说明文件没下全。另外 `file://` 下请使用 Chrome / Edge。

**Q：记录突然不见了？**
A：最常见的原因是 `index.html` 被挪到了别的文件夹（IndexedDB 按目录分区），挪回原目录即可恢复；其次是被清理了浏览器数据，这种情况只能从备份文件导入。

**Q：测出来的视力和医院的不一样？**
A：视标按 5 米标定边长绘制，**不做观看距离缩放**。如果孩子不是站在 5 米处测，结果本身就会有偏差，这不是 bug。屏幕校准也请务必先做一次。

**Q：数据会不会被传到网上？**
A：不会。整个项目没有任何网络请求、没有账号体系，数据库只存在你自己的浏览器里。
